# Init

## Input

```text
$ARGUMENTS
```

Read `.prdkit/workflows/protocol.md`, then follow `.prdkit/workflows/init.md`; for a 0.x
layout, `.prdkit/workflows/compact.md` (Cutover). If `.prdkit/workflows/` is missing, ask the
owner to run the kit's `scripts/init.sh` first. Setup does not authorize implementation or
publication.
